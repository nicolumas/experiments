Before anything ships

  • "Handsigniert" stays data-driven. The signature label comes from the edition_signature attribute (handsigniert, signiert, Nachlassstempel). Never hardcode it.
  • No live counters until the copies data is verified. Variant F depends on copiesLeft, the field the social-proof bar already reads. Sample value on this page is illustrative.
  • All strings are glossary keys, one per locale (EN, DE, FR). Check FR and EN line lengths before freeze.
  • Price mechanic copy (Startpreis steigt) must be suppressed for products flagged no_price_increase, which includes Suni today.

Why the current line fails

  • "100" has no unit. It reads as a model number, not as "only 100 exemplars exist".
  • English label inside an otherwise German spec block.
  • The Startpreis bar below depends on understanding the edition mechanic, and nothing on the page explains it.
  • The backend already sends "Auflage: 100" with a label. The frontend strips it before render, so this is cheap to fix.
