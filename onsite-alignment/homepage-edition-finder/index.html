My call

“Bekannt aus” sits directly above Trustpilot and was decided as one composition, so the two move together. If Brand wants the press band to stay put, only Trustpilot and the finder move.

Arm 2 · Redesigned2

“Welche Kunst passt zu dir?”

The same component, the same six subjects, six moods and six price bands, and the same results link. Only the template changes, plus a live preview of the first matching works.

  • Subject and mood are answered with real editions at their true ratio, each the work that ranks first for that answer in the live Artfinder: Kate Shaw for Landschaften, Beatrice Hug for Abstraktes, Hengki Koentjoro for Stimmungsvoll.
  • Budget comes last, worded “bis € 1.000” in the October 2026 price format.
  • No numbered rows and no boxed chips. Chosen answers lift and underline; the others are never faded.
  • The ivory band stays, as in the control, so the module reads as one object and ends clearly before the carousel below.
  • As answers change, the first four matching works appear, each linking to its product page. The CTA keeps production’s live count.
Handoff

The production component in components/edition-finder/ runs unchanged; the data-* contract on .chip, [data-row] and [data-finder-cta] is identical. New: the Twig template, an artwork per answer in the CMS props, styles, and the preview, which should reuse the component’s own count response.

Arm 3 · Fenster3

“Was siehst du aus deinem Fenster?”

The concept you chose on 14 October, rebuilt for the finder’s slot instead of beneath the hero, so it competes with the finder on equal terms. Five views, each pictured by a real edition, then “Mehr davon” or “Das Gegenteil”. Every answer is a preset of existing Artfinder parameters. It sits on the same ivory band as arm 2. The lede opens with the approved brand line “Kunst ist ein Fenster zur Welt.”

Changed from PROTO-2026-063

Unchosen views no longer fade to 45% (brandbook s06 forbids dimming artworks), and the results-page chips are out, so all four arms land on the same production results page.

Test design

One test, four arms

All three arms change the same section, so they cannot run as overlapping tests. Run them as one ABlyft test, 25% each, DE first. Arms 2 and 3 stay in today’s position, so a win cannot be confused with the move.

Primary

Finder click-through: homepage sessions with edition_finder_cta_click or a preview click. Today 3.8% of DE homepage-landing sessions (4.3% mobile, 2.3% desktop).

Secondary

Homepage to product page reach, finder views, Artfinder results views. Every event carries finder_ui and finder_position.

Guardrails

Add to cart (non-inferiority only, see sizing), Bestseller carousel clicks for arm 1, add to cart from intent channels, purchase rate.

Open points
Production issue, every arm

The Artfinder search answers the identical request with two different totals: 2,486 or 4,418 works with nothing chosen (3 of 8 calls vs 5 of 8 on 21 Oct), 280 or 545 for one selection. The finder CTA count therefore changes between page loads, the control included. Raise a ticket before the test starts.

  • ABlyft goals are marked unbound in the prototype until the 16-goal library is available; the primary metric above already exists in GA4.
  • Brandbook s04 names Helvetica Now Display for body text; the shop ships Archivo, and the arms keep the shop’s font so they differ only in content.
  • Answer labels changed from the CMS: “Portrait” to “Porträts”, “Ikonische Persönlichkeiten” to “Ikonen”, “Abstrakt” to “Abstraktes”. The topics behind them are unchanged.
  • The Letzte Exemplare carousel directly below keeps its production heading.
  • Next gate: a red-team pass, then a Jira ticket per arm.
